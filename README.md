# CallGuard — مسدودکننده پیش‌شماره تماس

یک اپ بسیار سبک که تماس‌های ورودی را **بی‌صدا و در پس‌زمینه** رد می‌کند. بدون نوتیفیکیشن، بدون سرویس دائمی. سیستم‌عامل خودش هنگام هر تماس آن را صدا می‌زند.

- روی گوشی‌های اندرویدی رایج کار می‌کند (اندروید ۱۰ به بالا / API 29+)
- **هم پیش‌شماره و هم شمارهٔ کامل** را بلاک می‌کند:
  - پیش‌شماره مثل `0942` → همهٔ شماره‌هایی که با آن شروع می‌شوند
  - شمارهٔ کامل مثل `09121234567` → دقیقاً همان تماس‌گیرنده
- چند مورد با `,` جدا می‌شوند، مثلا: `0942,09121234567`
- هیچ دسترسی خطرناکی نمی‌گیرد (فقط نقش «Call Screening»)
- پیش‌فرض: `0942`

## گرفتن فایل APK

### راه ۱ — بدون هیچ ابزاری (توصیه‌شده)
1. یک ریپازیتوری خصوصی در GitHub بسازید و محتوای همین پوشه را در آن آپلود کنید.
2. به تب **Actions** بروید؛ ورک‌فلو **Build APK** خودکار اجرا می‌شود.
3. بعد از پایان، از پایین صفحهٔ اجرا، آرتیفکت **CallGuard-debug-apk** را دانلود کنید. داخلش `app-debug.apk` است.

### راه ۲ — با Android Studio
پوشه را باز کنید و `Build > Build APK(s)` را بزنید، یا در ترمینال:
```
./gradlew assembleDebug
```
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## نصب و فعال‌سازی (فقط یک‌بار)
1. APK را روی گوشی نصب کنید (نصب از منابع نامعتبر را اجازه دهید).
2. اپ را یک‌بار باز کنید، پیش‌شماره‌ها را در صورت نیاز ویرایش و **ذخیره** کنید.
3. **فعال‌سازی بلاک تماس** را بزنید و در پنجرهٔ سیستم تأیید کنید.
4. تمام. دیگر لازم نیست اپ را باز کنید؛ در پس‌زمینه کار می‌کند.

> نکته: اندروید اجازه نمی‌دهد هیچ اپی بدون این یک‌بار تأیید، تماس‌ها را رد کند — این تنها مرحلهٔ اجباری است.
